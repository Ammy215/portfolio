## What it does

ThreatHunter looks up an indicator of compromise — an IP, domain, file hash or URL — and fans that single query out across five real threat-intelligence providers at once: AbuseIPDB, AlienVault OTX, IPInfo, VirusTotal and the NIST National Vulnerability Database. A Groq-powered assistant sits on top, able to answer questions against your own investigation history rather than just returning raw provider output.

## Architecture

The frontend is Next.js on the App Router with TypeScript; the backend is Express, also TypeScript, backed by Supabase for Postgres, auth and row-level security, with Zod validating everything that crosses the boundary between them.

It's a full 16-phase enterprise rebuild, and the engineering spec behind it is a real one: RS256 JWT authentication, timing-safe comparisons on anything security-sensitive, RFC 7807-shaped error responses, and CI with Trivy scanning dependencies for known vulnerabilities.

## Adversarial testing

This testing was AI-directed: I set the scope, Claude Code did the actual investigating and patching, and I reviewed and verified every fix.
